🎯 Resultados do Projeto

A implementação desta infraestrutura dedicada visa alcançar os seguintes marcos tecnológicos para o grupo ANTUR:

  • Preservação Digital: Salvaguarda de acervos imateriais e pesquisas sobre o Quilombo Mocambo.
  • Segurança de Dados: Proteção de informações sensíveis contra acessos externos não autorizados.
  • Estabilidade: Rede local cabeada e segmentada (VLANs) para alto desempenho de pesquisa.

🏢 Oportunidades no Condomínio

Ao integrar o ecossistema de laboratórios do CCSA, o ANTUR potenciará os seus resultados através de:

  • Modernização: Acesso ao incentivo de R$ 50.000,00 para aquisição de novos equipamentos.
  • Alta Disponibilidade: Infraestrutura escalável que garante o acesso ininterrupto ao acervo por investigadores remotos.
  • Colaboração: Integração técnica que facilita a divulgação científica e o intercâmbio de dados entre laboratórios do condomínio.

🛠️ Especificações de Implementação

Este ambiente é virtualizado via contentores, garantindo portabilidade total entre laboratórios.

Endereço do Dockerfile: /raiz_do_repositorio/Dockerfile

Ambiente: Nginx:Alpine | Deployment: AWS EC2 com Docker.
